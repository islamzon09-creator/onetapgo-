# دراسة كاملة لموقع Viby (joinviby.co.il) — أساس نسختنا الخاصة

> تاريخ الدراسة: 12 أكتوبر 2026
> الهدف: نبني خدمة/موقع بنفس الفكرة والهيكل، بهوية وأسماء ونصوص خاصة فينا.

---

## 1. الفكرة باختصار
Viby شركة إسرائيلية تبيع **أدوات رقمية لإرجاع الزبائن (Customer Retention)** للمصالح الصغيرة المحلية: مقاهي، مخابز، صالونات، مغاسل سيارات، محلات بوظة، مطاعم.
الشعار الأساسي: **"نُرجع الزبائن للمصالح"** — وكل شيء **بدون تطبيق** للزبون (QR / NFC + Apple Wallet / Google Wallet).

نموذج الربح: **اشتراك شهري لكل أداة لحالها**، التزام أول 3 أشهر ثم تجديد شهري. البيع كله عبر **واتساب + مكالمة + رابط دفع شخصي**.

## 3. هيكل صفحة المنتج (قالب واحد يتكرر لكل منتج)
كل صفحات المنتجات مبنية من **نفس القالب** بالترتيب هذا — هذا أهم شيء ننسخه:

1. **هيدر** + لوجو + شارة اسم المنتج.
2. **Hero:** سطر صغير فوق العنوان ← عنوان H1 فيه الكلمة المفتاحية للـ SEO ← فقرة شرح ← زرين: "احكوا معنا بواتساب" + "كيف بتشتغل" ← سطر صغير عن شروط الاشتراك.
3. **موك-أب تفاعلي** للمنتج (بطاقة "7 من 10"، عجلة بتلف، شاشة Wallet، صفحة روابط…).
4. **"زبائننا"** — شريط لوجوهات متحرك (marquee) لـ ~22 مصلحة.
5. **قسم Wallet** — "ينحفظ مباشرة بالـ Wallet!" + صورة Apple/Google Wallet + صورة زبونة بالمحل.
6. **"3 خطوات. هذي كل القصة."** (يمسح ← يحفظ ← يرجع ويربح).
7. **ديمو/فيديو** — "يلا اضغطوا! 😉".
8. **"التركيب كامل علينا"** — جاهز خلال 3 أيام عمل + 3 خطوات.
9. **"اللافتة هدية منّا"** — ستاند/لافتة مطبوعة بتصميم المصلحة مجاناً مع اشتراك 3 أشهر (الشحن على حساب الزبون).
10. **"ليش بتشتغل للمصلحة"** — 4 فوائد.
11. **بطاقة سعر** — "ابدأ صغير بـ… من 79₪ بالشهر" + 3 علامات ✓ + زر "بدي أبدأ".
12. **قسم مخصص للمنتج** (مثلاً أنواع الجوائز: هدية بالزيارة الجاية / خصم ذكي / جائزة نادرة).
13. **"كل شيء لازم تعرفه"** — مناسب لـ… / شو بتاخد المصلحة / كيف بتشتغل يومياً (زبون، طاقم، صاحب المصلحة) / السعر والتركيب / الخصوصية.
14. **"شو الفرق عن الحل العادي"** — البديل البسيط (بطاقة ورق) مقابل الحل تبعنا.
15. **FAQ** (6 أسئلة تقريباً).
16. **"حلول إضافية"** — روابط باقي المنتجات (cross-sell).
17. **CTA أخير** + واتساب + رقم تلفون.
18. **فورم Lead** (بالرئيسية): اسم + تلفون ← "بدي رابط دفع آمن" ← مندوب يتصل ويبعث رابط دفع (عبر Isracard).

## 4. الهوية البصرية (Design System)
- **الخط:** Heebo (عناوين ونص).
- **الألوان:** أساسي وردي فاقع `#FF2F83` · نص بنفسجي غامق جداً `#2A1830` · خلفية بيضاء `#FFFFFF` · لون بيج دافئ `#FEEFDC` · حقول إدخال `#FFFAFD` وحدود `#E1DFE2`.
- **الأزرار:** أساسي وردي، نص أبيض، حواف دائرية بالكامل (pill). ثانوي أبيض بحدود فاتحة وظل ناعم.
- **الحواف:** حوالي 18px للكروت.
- **الطابع:** مرِح، طاقة عالية، إيموجي كثير (🥐 ☕ 🎡 💳 ⭐)، نجوم ★ زخرفية، عناوين كبيرة جداً.
- **RTL** عبري بالكامل، Mobile-first.
- صورة OG موحدة 1200×630.

## 5. استراتيجية البيع والتسويق (السايكولوجيا)
- **السعر "يبدأ من"** والرقم الشهري كبير (79 / 49) بينما المبلغ الكامل لأول فترة (237 / 147) مكتوب صغير.
- **كل أداة لحالها** ← سهل يبدأ الزبون بأداة رخيصة وبعدين upsell.
- **هدية مادية** (اللافتة مجاناً) ← تكسر التردد وتعطي إحساس بقيمة ملموسة.
- **"التركيب كله علينا"** + **3 أيام عمل** ← تقليل المجهود والخوف.
- **Social proof:** لوجوهات مصالح حقيقية معروفة محلياً.
- **بدون تطبيق** متكررة بكل صفحة — أكبر اعتراض محلول.
- **قناة البيع:** واتساب برسالة جاهزة مسبقاً لكل منتج (`wa.me/...?text=...`).
- **ديمو مخصص لكل زبون محتمل:** صفحة على `myviby.co.il/d/<كود>` فيها **لوجو المصلحة نفسها** + عجلة بتلف + عرض خاص ("عرض خاص لمحلات القهوة: 149₪ بدل 199₪ لأول نصف سنة"). هاي أقوى حركة بيع عندهم — بيعملوا ديمو باسم المصلحة قبل ما يحكوا معها.
- **الإنستغرام:** الرابط جاي من bio الإنستغرام (utm_source=ig) ← الإعلانات والمحتوى على إنستغرام.
- **SEO:** كل صفحة لها كلمة مفتاحية واضحة بالـ H1 والعنوان (كرت ختم رقمي، عجلة حظ للمصالح، كرت NFC لتقييمات جوجل…) + keywords طويلة.
- **شفافية قانونية:** تنويهات عن الالتزام، الشحن، "עוסק פטור" بدون ضريبة، الخصوصية، وأن الأداة "لا تضمن تقييمات".

## 6. التقنية الملاحظة
- الموقع التسويقي: **Next.js** (صور `/_next/image`).
- النظام نفسه: تطبيق **Next.js على Vercel** (`customer-retention-system-six.vercel.app` ← `myviby.co.il`) مع **Firebase** (تخزين لوجوهات المصالح).
- الفيديو: **Vimeo**. الدفع: **Isracard** (رابط دفع). Apple/Google Wallet passes.
- مكونات النظام: صفحة انضمام للزبون (اسم + تلفون) ← إصدار بطاقة Wallet ← **تطبيق طاقم** (ختم/تحقق جائزة/خصم رصيد) ← **لوحة إدارة** لصاحب المصلحة ← صفحات ديمو مخصصة.

## 7. شو لازم نبني لنسختنا (خطة مبدئية)
**المرحلة 1 — الموقع التسويقي**
- اسم وهوية خاصة فينا (لون، لوجو، خط عربي/عبري).
- رئيسية + صفحة لكل منتج بنفس القالب (قسم 3).
- لغة: تحديد (عبري / عربي / الاثنين).
- فورم Lead + واتساب برسائل جاهزة.

**المرحلة 2 — المنتجات الأسهل للبدء (بدون برمجة معقدة)**
- **ستاند NFC للتقييمات** + **ستاند NFC لصفحة روابط** — منتج مادي نطبعه (ميزة: عندنا طباعة 3D!) + صفحة روابط قابلة للتعديل.

**المرحلة 3 — النظام الرقمي**
- بطاقة ختم رقمية + Wallet passes.
- عجلة حظ مع جوائز/احتمالات.
- تطبيق طاقم + لوحة إدارة.
- صفحات ديمو مخصصة لكل مصلحة.

**المرحلة 4 — متقدم**
- بطاقة هدايا مع دفع.
- محادثة واتساب بالـ AI بعد الزيارة.
